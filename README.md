# C++ DSA (Data Structures and Algorithms)

This repository contains practical C++ exercises demonstrating basic concepts essential for DSA:
- I/O, math, functions, conditionals, loops, arrays.
- Menu-driven program with 7 exercises, including Codility FrogJmp sample.

## Run
```bash
g++ cpp-dsa.cpp -o cpp-dsa
./cpp-dsa
```

## Exercises
1. Days to seconds (long long cast)
2. Sphere volume (M_PI, pow)
3. Square geometry (functions)
4. Char case (ctype)
5. While loop pseudocode
6. Array average (std::array)
7. FrogJmp (ceil math)

Branch `blackboxai/comments-added` adds detailed comments explaining each part.
